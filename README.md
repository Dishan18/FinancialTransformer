# Does Regime-Gated Attention Help Stock Return Prediction?

**A leakage-controlled, pre-registered evaluation of the Adaptive Financial Transformer (AFT)**

📄 Paper (arXiv, v2): https://arxiv.org/abs/2606.29347 · 💾 Software DOI (all versions): https://doi.org/10.5281/zenodo.21109641

> **Version 2 supersedes version 1.** The v1 preprint and the v1 version of this repository reported
> results that its experiments did not support: baseline confidence intervals and ablation numbers that no
> experiment produced, no transaction costs although 0.05 % was stated, a different dataset than described,
> and more. The full audit is in [`AUDIT.md`](AUDIT.md). Every result below was regenerated by the code in
> this repository.

## Main findings

| Question | Result |
|---|---|
| Does the AFT beat simple forecasts on a single stock (AAPL, corrected protocol)? | **No.** The training-mean forecast (buy & hold) has MAE 3.08 % and a net Sharpe ratio of 0.99; the AFT has 3.15 % and 0.28. The zero forecast has MAE 3.12 %. |
| Do the AFT's regime gate and financial-context bias do anything? | **No.** Learned gates are 0.9982 of maximal entropy (almost uniform), and the context bias is 2 % of the attention-logit scale. A product of two softmaxes attenuates it by 1/G. Removing the components changes nothing (paired p ≥ 0.21). |
| Does breadth help? (point-in-time S&P 500 vs 100 large caps, development period 2016–2022) | **Yes.** XGBoost rank IC 0.0059 (t = 0.78) on 100 stocks → 0.0155 (t = 2.00) on the S&P 500 at 5 days, and 0.0345 (t = 2.54) at 21 days. |
| AFT vs a vanilla Transformer on the S&P 500 panel? | **Indistinguishable.** IC 0.0332 vs 0.0319 (p = 0.87) in development; ΔIC −0.0012 (p = 0.91) on the holdout. Both are less stable than XGBoost and ridge. |
| Do learned meta-learners (stacking, gating, skill weighting) beat equal weighting? | **No.** All six learned combiners lose to equal-weight ranks at both horizons. |
| **Sealed, pre-registered holdout (2023–2025)** | **Primary system (21-day) failed:** rank IC 0.0003, one-sided p = 0.49, net Sharpe ratio 0.08. **The 5-day version survived** (pre-registered secondary): IC 0.0172 (t = 1.77, one-sided p = 0.038), positive in every year, net Sharpe ratio 0.34 at 5 bp (0.62 with the regime exposure gate). |

The 5-day result is a secondary analysis. It needs confirmation on new data (e.g. 2026 onward) before it can be
called established.

## Reproducing the results

Python 3.11 with [`requirements-repro.txt`](requirements-repro.txt) (CUDA build of PyTorch 2.11). Each runner
skips work that is already done, and CUDA kernels are deterministic wherever PyTorch provides them.

```bash
# --- panel study (v2) ---
python scripts/v2_download_sp500.py               # prices for the S&P 500 constituents (data/sp500_constituents_2026-11-21.csv)
python scripts/v2_download.py                      # 100-stock universe + SPY + VIX + sector ETFs
python scripts/v2_build_panel.py                   # 100-stock panel + look-ahead test
python scripts/v2_build_panel_pit.py sp500         # point-in-time S&P 500 panel (h = 5, 21) + look-ahead test
python scripts/v2_walkforward.py Ridge XGBoost MLP --panel=sp500 --horizon=5
python scripts/v2_walkforward.py Ridge XGBoost MLP XGBoost-IC --panel=sp500 --horizon=21
python scripts/v2_walkforward.py Transformer AFT AFT-R --panel=sp500 --horizon=21 --stride=5
python scripts/v2_evaluate.py --panel sp500 --horizon 21 --models Ridge,XGBoost,MLP   # development period only
python scripts/v2_meta.py --panel sp500 --horizon 5 --models Ridge,XGBoost,MLP --tag v3
python scripts/v2_metasystem.py --panel sp500 --horizon 21
python scripts/v2_holdout.py                       # the single pre-registered holdout evaluation
python scripts/v2_paper_numbers.py                 # paper/numbers.tex, tables, figure
# --- single-stock (AAPL) study ---
python scripts/run_aapl.py base && python scripts/run_aapl.py ablation
python scripts/analyze.py && python scripts/diagnostics.py
```

## Protocol in one paragraph

Features use only data up to the close of the forecast date, which is verified by recomputing them on
truncated data. A stock enters the universe only on its S&P 500 addition date. Models are refitted yearly on
an expanding window, with a 252-day validation block and purges of h days. The development period
(2016–2022) was used for every design decision. The holdout (2023–2025) stayed sealed until
`PREREGISTRATION.md` was written, and was then evaluated once (`results_v2/summary/UNSEAL_LOG.txt`).
Rank ICs use Newey–West standard errors (lag h − 1). Long-short quintile portfolios are cost-aware
(per side, on traded notional), non-overlapping, and averaged over all rebalancing phases.

## Limitations

The universe is today's S&P 500 members (survivorship bias); prices are Yahoo Finance adjusted closes;
costs are proportional (no market impact or borrowing fees); the holdout spans only three years.
